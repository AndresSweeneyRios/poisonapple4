Portfolio metadata

scripts/metadata.mjs is the source for title, description, social tags, canonical
URL, and the JSON-LD graph. Vite injects this into both development and static
production HTML. Keep claims aligned with visible portfolio copy.

Schema: Person, WebSite, ProfilePage, three CreativeWork projects and one
SoftwareSourceCode project. Project URLs point at real section anchors. No
invented ratings, pricing, qualifications, traffic numbers, or review snippets.

The original public/thumbnail.jpeg (1200x620 JPEG) is the canonical preview
for Open Graph, Twitter and JSON-LD. Its dimensions, type and alt text share
one configuration in scripts/metadata.mjs. npm run seo:images validates it and
updates the legacy social-preview.png URL with the same artwork; it does not
redesign the thumbnail or overwrite favicons. Public files are included in npm run build. Social cards are intended for shared links; Google controls
its own result layout and may rewrite titles/descriptions.

The sitemap includes only the canonical homepage. Fragment anchors are not
separate indexed pages. The obsolete 2024 lastmod and daily update hint were
removed rather than replaced with a misleading build-time date. robots.txt
allows crawling. Static HTML exposes the actual portfolio without JavaScript.

No special AI-only tags or llms.txt are required for Google's AI search features.
The page has a semantic heading hierarchy and JSON-LD to make entity/project
relationships explicit. Adding this does not guarantee a special search result.

Locally checked: JSON parses, graph references and project anchors resolve,
metadata names are unique, one H1, unique document IDs, public image dimensions,
canonical URL and sitemap. External rich-result testing and Search Console
inspection require the deployed URL and have not been performed for this draft.
